# Contributing

Keep contributions focused on reusable knowledge-site behavior.

- Write source lessons in `content/*.md`.
- Add their metadata to `content.manifest.json`.
- Put images in `public/imgs/` and PDFs in `public/pdfs/`.
- Run `npm run assets:check`, `npm test`, and `npm run build` before opening a pull request.
- Do not add brand-specific content or a client-side framework unless the template requires it.
